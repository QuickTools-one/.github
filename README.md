# QuickTools.one

Fast, private, browser-based tools for PDFs and images — all running locally on your device.  
No uploads. No tracking. No servers.

---

## 🚀 About QuickTools.one
QuickTools.one is a growing suite of lightweight utilities designed to handle everyday PDF and image tasks directly in your browser.  
Everything is powered by client-side JavaScript and WebAssembly for **instant, secure, offline-friendly processing**.

---

## 🧰 Tools We Build
- **Merge PDF**
- **Split PDF**
- **Compress PDF**
- **Resize Images**
- **Convert Images to PDF**

More tools are added weekly as the project evolves.

---

## 🔒 Privacy First
Your files **never leave your device**.

- No accounts  
- No tracking  
- No analytics tied to file content  
- No server uploads  

Every tool is built to be simple, fast, and trustworthy.

---

## 🎯 Mission
To build useful, fast, “boring” tools that help millions of users — and to do it fully in public while optimizing for long-term SEO growth.

---

## 🛠️ Tech Stack
- Next.js  
- TypeScript  
- WebAssembly (WASM)  
- PDF & image manipulation libraries  
- 100% client-side processing
